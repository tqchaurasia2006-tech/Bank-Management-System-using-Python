# Bank-Management-System-using-Python

This project, I have developed a ***Bank-Management-System using Python and Microsoft Excel***.

The objective of this project is to simulate basic banking operations through a simple console-based application.

The project is developed using Python, and instead of using a database like MySQL, I have used Microsoft Excel as the backend database with the help of the **OpenPyXL** library. This library allows Python to read, write, and update Excel files efficiently.

The application provides a user-friendly menu with the following features:

* Create a new bank account 
* Secure login using Account Number and PIN 
* Deposit money
* Withdraw money
* View current account balance 
* Logout and return to the main menu 

Whenever a new account is created, the account details are automatically stored in the Excel file. During login, the system verifies the account number and PIN before allowing access. After successful login, the user can perform banking operations, and every transaction updates the balance in the Excel sheet permanently.

This project helped me understand important programming concepts such as functions, loops, conditional statements, file handling, and working with Excel files using Python.
